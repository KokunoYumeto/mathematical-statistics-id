2. Reserve stable IDs and the exact contiguous source boundary.

4. Resolve only its direct assets; exclude or externally link components whose
   redistribution rights are unproved.
5. Build the offline target deterministically.
6. Run structural/math/ID/link/rights/privacy/accessibility and desktop/mobile
   checks; fix substantive findings once, then stop auditing and advance.
7. Append the translation/backend/build/QA records and exact hashes.
8. Advance CURRENT_CURSOR immediately to the next source page.
9. At a substantial verified boundary, update and push the lane repository and
   release evidence without asking the user to reconfirm the desired outcome.
